9Wings App Manager

Connect to GitHub

This page sends messages and updates to everyone using the 9Wings app. It needs a GitHub access key for the sheranr/9wings-app repository.

  1. On GitHub, open Settings → Developer settings → Fine-grained tokens → Generate new token.
  2. Name: 9Wings manager. Expiration: 1 year.
  3. Repository access: Only select repositories → 9wings-app.
  4. Permissions → Repository: Contents: Read and write and Actions: Read and write.
  5. Click Generate token and paste it below.

Keep this key private. Anyone with it can change the app's messages and start new builds. Only use "Remember" on your own computer or phone.
